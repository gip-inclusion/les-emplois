À quoi sert ce code ?

Ce code de récupération vous permet de vous connecter à votre compte si vous n'avez plus accès à votre application d'authentification (par exemple, en cas de perte ou de changement de téléphone).

Il vous permet de remplacer exceptionnellement le code de validation unique (OTP)

Important : ce code ne remplace pas votre mot de passe. Vous devrez toujours saisir votre adresse e-mail et votre mot de passe pour vous connecter.

Attention : ce code ne peut être utilisé qu'une seule fois !

Une fois utilisé, votre code de récupération sera définitivement invalidé. Il vous permettra de retrouver l'accès à votre compte et de configurer une nouvelle application d'authentification sur un appareil.

Un nouveau code de récupération sera alors généré. Pensez à le conserver précieusement pour vos prochains besoins.

Comment conserver votre code en toute sécurité ?

  • Imprimez ce document et conservez-le dans un endroit où vous pourrez facilement y accéder en cas de besoin, comme votre portefeuille.
  • Ne partagez jamais ce code avec une autre personne.
  • Ne le stockez pas au même endroit que l’application qui génère le code.
  • Ne le stockez pas dans un fichier non protégé ou dans un espace accessible à d'autres personnes.

Ce code est personnel et confidentiel. Toute personne qui le possède pourrait l'utiliser pour franchir la deuxième étape de vérification de votre connexion.
